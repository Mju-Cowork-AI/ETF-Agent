맞춤 상품 추천은 아직 제공하지 않습니다. 특정 상품을 골라 드리는 대신, 직접 비교해 보실 수 있도록 객관적인 정보를 보여 드릴게요.

ETF를 비교할 때는 아래 기준을 함께 보세요.
- 총보수: 운용·판매·수탁·사무관리에 드는 연간 보수
- 실부담비용: 총보수에 기타비용과 매매·중개수수료를 더한, 투자자가 실제로 부담하는 비용
- 순자산: 펀드의 규모
- 기초지수: ETF가 따라가는 지수
- 분배 주기: 분배금을 주는 간격(월·분기 등)

비교하고 싶은 ETF 이름을 2~3개 넣어 "○○이랑 ○○ 비교해줘"처럼 물어보시면 위 기준으로 비교해 드려요.
