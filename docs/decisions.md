# 결정 기록

- 결정이 바뀌면 이 문서를 먼저 고치고 스탠드업에서 알립니다.
- 공수(h)는 **추정**입니다. 11-22(일)에 실제 소요 시간을 재고 남은 일을 다시 계산했습니다(아래 "공수 실측").
- **기반(D1 결정):** **FastAPI 기반**: Python + FastAPI + Postgres(pgvector) + React + Docker + LangGraph
  - Streamlit 기반(Python + Streamlit + SQLite + LangGraph)은 **옮겨 올 강점의 출처**로만 씁니다.
- **공통 기능 집합:** 이번에 만드는 기준 범위입니다. 필수 범위 + 멀티턴(D16) + 수준별 답변 3단계(D12) + 피드백 저장, ETF 5개(D4), 평가셋 60문항(D17), 사용자 테스트 최소 3명(입문 수준 1명 필수, 11-21)입니다([plan.md](plan.md) 1장).
- **팀 용량:** 개발 가능일 10일 × 4명 × 하루 모듈 작업 약 5.07~5.73h = 약 203~229h로 계획했습니다([plan.md](plan.md) 6장). 실측(11-22) 결과 지금까지 하루 평균 약 3~4h였고, 이 속도로도 남은 7일 용량이 남은 일보다 큽니다. 빠지는 날은 11-22에 받았습니다(AI Engineer 11-28~29, Data Scientist 11-27 10~18시)
- **공수(추정 이력):** 공통 기능 집합 약 232h → 범위 조정(11-18) 후 약 214h → D6 개념 문서 수정(+4.5h, 11-19) 후 약 218.5h → 범위 조정 2차(−24h, 11-21) 후 약 194.5h. 194.5h는 온보딩 등을 넉넉히 잡은 추정이었습니다.
- **공수(11-22 실측):** 지금까지 쓴 시간 합계 **78h**(AI Engineer 16h, Data Scientist 19h, Cloud Engineer 18h, AI Solutions Architect 25h). 남은 일 약 **65h** → 범위 조정 3차(약 −11.5h) 후 약 **53.5h**
