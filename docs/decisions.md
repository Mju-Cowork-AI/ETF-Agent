# 결정 기록

- 결정이 바뀌면 이 문서를 먼저 고치고 스탠드업에서 알립니다.
- 공수(h)는 모두 **추정**입니다. 11-22(일)에 실제 소요 시간으로 다시 계산합니다.
- **기반(D1 결정):** **FastAPI 기반**: Python + FastAPI + Postgres(pgvector) + React + Docker + LangGraph
  - Streamlit 기반(Python + Streamlit + SQLite + LangGraph)은 **옮겨 올 강점의 출처**로만 씁니다.
- **공통 기능 집합:** 이번에 만드는 기준 범위입니다. 필수 범위 + 멀티턴 + 수준별 답변 3단계 + 피드백 저장, ETF 5개, 평가셋 60문항입니다([plan.md](plan.md) 1장).
- **팀 용량:** 개발 가능일 12일 × 4명 × 하루 모듈 작업 약 5.07~5.73h = **약 243~275h**([plan.md](plan.md) 6장)
- **공수:** 공통 기능 집합 약 **232h**(조건부 240h), 여유 약 **11~43h(약 5~16%)**
