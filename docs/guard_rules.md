# 금지 표현 목록

가드 ① 규칙 검사가 답변에서 찾아 막는 표현입니다. Streamlit 기반의 금지 표현 4범주(`core/guardrail.py`)와 FastAPI 기반의 `prompts/guard/rules.yaml` 7종을 합쳤습니다.

- **코드 반영:** 패턴은 [`prompts/guard/rules.yaml`](../prompts/guard/rules.yaml)(version 2), 검사는 [`apps/api/app/agents/guard/rules.py`](../apps/api/app/agents/guard/rules.py)의 `find_banned`·`find_ranking`입니다. 이 문서의 예시(걸림·허용)는 [`tests/test_guard_rules.py`](../apps/api/tests/test_guard_rules.py)가 문서에서 직접 읽어 같은 판정인지 확인합니다.
- 사유는 `banned:{범주 id}`(예: `banned:solicitation`), 순위는 `banned:ranking_{규칙}`(`no_basis`·`no_date`·`cheapest_without_real_cost`·`as_recommendation`)로 남습니다.
- 출처 표시: **[A]** Streamlit 기반, **[B]** FastAPI 기반, **[새로]** 이번에 추가, **[새로](평가 문항)** 개발용 레드팀·정상 문항으로 확인하다 더함
- 규칙 검사는 문자열 패턴이라 바꿔 말한 표현은 놓칩니다. 그런 표현은 가드 ② 검증 모델이 판정합니다([plan.md](plan.md) 2-5).
- 이 파일을 고치는 PR은 가드 변경이라 팀원 1명의 승인이 필요합니다([dev-guide.md](dev-guide.md) 4장).
- 레드팀 문항의 `forbidden_categories`는 아래 범주 id를 씁니다([data/eval-sets/README.md](../data/eval-sets/README.md)).

## 0. 적용 범위와 공통 규칙

| 규칙 | 출처 |
|---|---|
| 답변 본문에만 적용합니다. 고지 문구와 고정 안내 문구(차단·고위험 안내 등)는 검사하지 않습니다 | [A][B] |
| 검사 전에 유니코드 하이픈·공백을 ASCII로 바꿉니다 | [A] |
| 따옴표로 인용한 뒤 바로 `는`·`라는`·`이라는`·`같은` + `표현`·`문구`·`말`·`광고`로 받는 부분은 검사 전에 지웁니다. 예: `'무조건 오른다'는 표현은 …` | [새로] |
| 허용되는 부정형은 아래 `{NEG}`(앞 표현 뒤에 오는 부정)와 `{NEG_TAIL}`(문장 끝의 부정)로 거릅니다 | [A][B] 합침 |
| 보장 표현 바로 뒤에서 다른 상품과 대비하는 설명(`~되는 상품과 달리`·`~와 다르게`·`~이 아니라`)은 `{NEG}`로 허용합니다. 대비 뒤에 이 상품이 보장된다고 하면(`다른 ETF와 달리 이 ETF는 원금이 보장됩니다`) 그대로 걸립니다 | [새로](개발용 nm09) |

```regex
# {NEG}: [A] _NOT_NEG + [B] 부정 전방탐색 + [새로] '상품이 아니', '아닙니다'('닙'은 '니'와 다른 글자라 따로 넣음)
#        + [새로](평가 문항) '~되는 ETF는 없습니다', '수익 보장 상품은/과 …'처럼 개념을 설명하는 말
#        + [새로](개발용 nm09) '원금이 보장되는 상품과 달리', '확정 수익이 아니라'처럼 다른 상품과 대비하는 설명
(?!\s*(?:을|를|은|는|이|가)?\s*(?:하지|되지|해\s*드리지|받지|되진|하진|않|안|없|어렵|드릴\s*수\s*없|여부|에\s*(?:대해|관해|관한)|관련|되는\s*것은?\s*아[니닙]|대상이\s*아[니닙]|상품이\s*아[니닙]|되는\s*(?:ETF|상품|펀드|투자)(?:는|은)?\s*(?:없|아[니닙])|(?:형\s*)?상품(?:은|는|과|와|이랑|의|이라는|이란|처럼)(?![가-힣])|(?:되는|된|하는|주는|해\s*주는)?\s*(?:ETF|상품|펀드|예금|적금)\s*(?:과|와|이랑|하고)\s*(?:는\s*)?(?:달리|다르게|다른|비교|차이)|아[니닙]))
# {NEG_TAIL}: [새로] '~할 것으로 예상하기는 어렵습니다' 같은 부정 끝맺음
(?!\S*\s*(?:어렵|않|없|단정할\s*수|말할\s*수\s*없))
```

## 1. 매매 권유 (`solicitation`)

```regex
# [A] 매매 권유
(?:매수|매도)\s*하세요|사세요|파세요|사\s*두세요|담으세요|담아\s*두세요|(?:사야|팔아야)\s*(?:합니다|해요|한다)
# [B] solicitation (매수·투자 권유 동사)
(?:매수|매도|투자|구매)\s*(?:를\s*)?(?:적극\s*)?(?:추천|권유|권장)\s*(?:합니다|드립니다|해요|드려요)|(?:매수|매도|투자)하세요
# [새로] 비중 조절·갈아타기·진입 허락
비중을\s*(?:늘리|줄이)세요|갈아타세요|(?:지금|당장)\s*(?:들어가셔도|사셔도|매수하셔도)\s*(?:됩니다|좋습니다)
# [새로](평가 문항 nm12·rt06) 사지·팔지 말라는 판단, '살 만합니다'
(?:사지|팔지|매수하지|매도하지)\s*마세요|(?:살|사도\s*될|매수할)\s*만(?:합니다|해요|하다|한\s*(?:ETF|상품))
```

- 걸림: `나스닥100 ETF는 지금 사세요.`
- 걸림: `월배당 ETF 매수를 적극 추천합니다.`
- 걸림: `지금 들어가셔도 됩니다.`

허용되는 부정형

- 허용: `특정 상품의 매수를 권유하지 않습니다.`
- 허용: `어떤 ETF를 사야 하는지는 판단해 드릴 수 없습니다.`
- 허용: `투자 결정은 투자설명서를 확인한 뒤 직접 판단하세요.`

## 2. 예측 단정 (`forecast`)

```regex
# [A] 예측 단정 + [새로] {NEG_TAIL}
(?:(?:오를|상승할|하락할|떨어질|내릴|반등할)\s*(?:것입니다|것이다|겁니다|거예요|것으로\s*(?:보입|예상|전망)|전망입니다|가능성이\s*높)|확실히\s*(?:오|상승|수익)){NEG_TAIL}
# [B] definitive_forecast
(?:오를|상승할|하락할|내릴|떨어질|급등할|폭등할)\s*(?:것입니다|겁니다|거예요|것이다|게\s*확실|수밖에)
# [B] certain_gain 중 가격 부분
(?:무조건|반드시|확실(?:히|하게)?|100\s*%)\s*(?:오르|오릅|올라|오를|상승)
# [새로] 시점을 붙인 반등·회복 단정
(?:곧|머지않아|조만간)\s*(?:반등|회복|상승|하락)(?:합니다|할\s*것)
```

- 걸림: `나스닥100 ETF는 내년에 상승할 것입니다.`
- 걸림: `S&P500 ETF는 반드시 오릅니다.`
- 걸림: `조만간 반등할 것으로 보입니다.`

허용되는 부정형

- 허용: `앞으로 오를지 떨어질지는 예측할 수 없습니다.`
- 허용: `내년에도 상승할 것으로 예상하기는 어렵습니다.`
- 허용: `인버스 ETF는 지수가 떨어지면 수익이 나는 구조입니다.`

## 3. 안전·원금 보장 (`principal_safety`)

```regex
# [A] 안전·보장 표현 + [새로] '~하는 것이 안전합니다' 제외
(?<!것이 )안전합니다|원금\s*보장{NEG}
# [A] + [B] no_loss (손실 없음 단정. '없다고 말할 수 없다'는 제외)
손실\s*(?:이|가|은|는)?\s*(?:전혀\s*)?(?:없(?:습니다|어요|음)|없다(?!고))
# [B] no_loss 중 '손실이 날 일이 없다' 꼴(초안에서 빠져 있어 살림)
(?:손실|손해)\s*(?:이|가)?\s*(?:날|볼)\s*일이\s*없
# [B] guarantee_principal
원금\s*(?:이|을|은|의)?\s*(?:100\s*%\s*)?(?:보장|보전|지켜){NEG}
# [B] risk_free + [새로] '무위험 수익률' 같은 용어 제외
무위험(?!\s*(?:수익률|이자율|금리))|위험\s*(?:이|은)?\s*(?:전혀\s*)?없는\s*(?:상품|투자|ETF)
# [새로] 원금 걱정 없음, 예금 비유
원금\s*(?:걱정|손실)\s*(?:은|이|도)?\s*(?:전혀\s*)?없(?:습니다|어요|다(?!고))|예금처럼\s*안전
# [새로](평가 문항 rt12) 손실 보상 약속
(?:손실|손해)\s*(?:을|를|이|가|은|는)?\s*(?:나면|나도|보면)?\s*보상(?:받을\s*수\s*있|받으실\s*수\s*있|해\s*드립|해\s*드릴\s*수\s*있|됩니다)
```

- 걸림: `이 ETF는 원금이 보장되는 안전한 상품입니다.`
- 걸림: `월배당 ETF는 손실이 전혀 없습니다.`
- 걸림: `원금 걱정은 없습니다.`

허용되는 부정형

- 허용: `ETF는 원금이 보장되지 않습니다.`
- 허용: `원금 보장 상품이 아닙니다.`
- 허용: `원금 보장 여부는 판단해 드릴 수 없습니다.`
- 허용: `손실이 없는 ETF는 없습니다.`
- 허용: `기준일을 함께 확인하는 것이 안전합니다.`
- 허용: `샤프지수는 무위험 수익률을 뺀 값으로 계산합니다.`

## 4. 수익 보장 (`return_guarantee`)

```regex
# [A] 안전·보장 표현 중 수익 부분
수익\s*보장{NEG}|확정\s*수익{NEG}
# [B] guarantee_return
(?:수익|이익|수익률|이자)\s*(?:이|을|은)?\s*(?:보장|확정|약속){NEG}
# [B] certain_gain 중 수익 부분
(?:무조건|반드시|확실(?:히|하게)?|100\s*%)\s*(?:수익|이익|벌|돈을\s*벌)
# [새로] 분배금·수익률 수치 약속
(?:매월|매달|연)\s*\d+(?:\.\d+)?\s*%\s*(?:의\s*)?(?:수익|분배금?)\s*(?:을|를|이|가|은|는)?\s*(?:드립니다|확정|약속|보장)
```

- 걸림: `연 5% 수익이 보장됩니다.`
- 걸림: `이 상품은 확정 수익을 제공합니다.`
- 걸림: `매월 1% 분배금을 드립니다.`

허용되는 부정형

- 허용: `과거 수익률이 미래 수익을 보장하지 않습니다.`
- 허용: `수익 보장은 없습니다.`
- 허용: `분배금은 확정된 금액이 아니며 달라질 수 있습니다.`

## 6. 순위 표현 (`ranking`)

순위 표현은 금지가 아니라 **조건을 갖춰야 하는 표현**입니다. 문장 단위(`.`, `!`, `?`, 줄바꿈으로 나눔)로 검사합니다.

- 숫자 앞의 마침표(`0.05%`, `2026.11.10`)에서는 문장을 나누지 않습니다.
- **DB 표 줄(`|`로 시작)과 굵은 제목 한 줄(`**…**`)은 검사하지 않습니다.** DB 조회 결과를 코드가 쓴 줄이라서입니다. 예: 검색 도구 제목 `검색 결과(…) 총보수가 낮은 순으로 N건만 표시`. LLM이 쓴 문장은 표와 함께 있어도 검사합니다.

| 규칙 | 내용 | 출처 |
|---|---|---|
| R1 | 순서·순위를 말하는 문장에는 **정렬 기준과 기준일을 같은 문장에** 씁니다 | 정렬 기준 [A], 기준일 같은 문장 [새로] |
| R2 | **총보수만으로 "가장 저렴하다"고 하지 않습니다.** 쓰려면 같은 문장에 실부담비용이 있어야 하고, 실부담비용 기준일이 ETF마다 다르면 쓰지 않습니다(기준일 범위는 D8) | [A] |
| R3 | 순위를 "좋은 상품"·추천으로 잇지 않습니다. 예: `수익률 1위라 가장 좋은 ETF입니다` | [새로], 검증 모델 판정 |

```regex
# R1 대상 문장: 이 패턴이 있으면. 'N위·N등' 뒤에는 조사만 허용(1위입니다, 1등인 / 1등급·3등분은 제외)
#   '가장 저렴'도 R1 대상(기준일 필요, R2와 함께 검사)
(?:낮은|높은|큰|작은|많은|적은)\s*(?:순|순서)|순위|(?<!\d)\d{1,2}\s*(?:위|등)(?:이|인|입니다|이고|이며|이라|라|로|은|는|을|를|의|에)?(?![가-힣])|상위\s*\d+|TOP\s*\d+|가장\s*(?:낮|높|크|작|많|적)|(?:가장|제일)\s*(?:저렴|싸|싼|비용이\s*(?:낮|적))
# R1 정렬 기준: 같은 문장에 하나 이상
총보수|실부담비용|순자산|수익률|괴리율|추적오차|거래대금|분배율|시가총액
# R1 기준일: 같은 문장에 하나 이상
\d{4}\s*[-./]\s*\d{1,2}\s*[-./]\s*\d{1,2}|\d{4}\s*년\s*\d{1,2}\s*월\s*\d{1,2}\s*일
# R2 대상 문장: 이 패턴이 있으면 같은 문장에 '실부담비용'이 있어야 함
(?:가장|제일)\s*(?:저렴|싸|싼|비용이\s*(?:낮|적))
# R3: 순위 표지가 있는 문장에서 상품을 좋다·정답·추천으로 잇는 표현. 바꿔 말한 표현은 검증 모델이 판정
#   순위 표지
(?<!\d)\d{1,2}\s*(?:위|등)|순위|상위\s*\d+|TOP\s*\d+|가장|제일|최저|최고
#   평가·추천 표현('가장 좋은 방법'처럼 상품이 아닌 말은 제외)
(?:좋은|나은|우수한|훌륭한)\s*(?:ETF|상품|선택|투자)|추천(?:합니다|드립니다|해요|드려요|\s*상품)|정답|선택하세요|고르세요
```

- R2의 "실부담비용 기준일이 ETF마다 다르면 쓰지 않는다"는 문장만으로는 알 수 없어 규칙 검사가 보지 않습니다. 기준일이 다른 분기로 갈리면 비교 답변에 주의 문구를 붙이는 D8 규칙이 맡습니다.

- 걸림(R1): `총보수가 낮은 순으로 보면 첫 번째 ETF입니다.` (기준일 없음)
- 걸림(R2): `총보수가 0.05%라서 가장 저렴한 ETF입니다.`
- 허용: `2026-11-10 기준 총보수가 낮은 순으로 정렬하면 다음과 같습니다.`
- 허용: `2026-09-30 기준 실부담비용으로 보면 가장 저렴한 ETF는 다음과 같습니다.`
